Un proyecto de Python con el framework fastAPI para crear tu propio curriculum con tus datos, contactos, experiencia laboral, etc. 
1.- Primero descarga el archivo en "Code" y "download ZIP" 
2.- Segundo, una vez descargado es después extraer el archivo para abrirlo en Visual Studio Code 
3.- Tercero, es darle a la flecha para empezar a ejecutarlo y convertirlo en index.html 
4.- Y ya tendrías tu propio curriculum! 
OJO! puedes modificar datos en casos de que lo llegues a necesitar
